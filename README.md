# 💳 Credit Card Fraud Detection

An end-to-end Machine Learning project that identifies potentially fraudulent credit card transactions using a Random Forest model and an interactive Streamlit dashboard.

## 📊 Dashboard Preview

![Credit Card Fraud Detection Dashboard](dashboard.png)

## 🚀 Features
- Credit card fraud prediction
- Random Forest machine learning model
- Interactive Streamlit dashboard
- Transaction analysis and visualizations
- Fraud risk assessment

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## 📈 Model Performance
- Precision: 96.49%
- Recall: 74.32%
- F1-score: 83.97%
- ROC-AUC: 94.33%

*Metrics are from the independent test dataset.*

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
